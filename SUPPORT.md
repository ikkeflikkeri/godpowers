# Support

Something not working, or not making sense? Here is where to go.

## Where to get help

| What you have | Where it goes |
|---|---|
| Something is broken | Open a GitHub issue |
| An idea for a feature | Open a GitHub issue using the feature-request template |
| A question, not a bug | GitHub Discussions |
| A security vulnerability | **Do not open an issue.** See [SECURITY.md](SECURITY.md) for private reporting. |

That last row matters. Reporting a vulnerability publicly puts every user at
risk during the window before a fix ships.

## Before you open an issue

Two commands answer a surprising number of questions on their own:

```
/god-doctor      diagnoses install and state problems
/god-status      shows what Godpowers currently believes about your project
```

If you do open an issue, including the output of those two makes it much faster
to help you.

## What to expect

This is a community project, maintained on a best-effort basis. Response times
vary. Issues are triaged by severity and impact rather than by arrival order, so
a small report about a broken install may well be answered before a large
feature discussion.
