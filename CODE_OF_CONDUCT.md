# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

The short version: be decent to people. Assume good faith, critique the work
rather than the person, and accept that other contributors may know things you
do not.

## Reporting

To report a violation, either open a private security advisory on GitHub or
contact the maintainers through the channel listed in [SUPPORT.md](SUPPORT.md).

Reports are handled privately. You will not be asked to confront the other
person, and you do not need to have documented everything perfectly before
speaking up.
